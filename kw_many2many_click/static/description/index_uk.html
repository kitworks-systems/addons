Клікабельні записи Many2Many


Модуль додає клікабельний віджет для полів many2many в Odoo 18. Він зберігає стандартний зовнішній вигляд у стилі тегів і додає зручну навігацію: клік по тексту елемента відкриває форму пов'язаного запису в поточній вкладці.

Основні можливості:

  • Працює з усіма полями many2many
  • Відкриває форму пов'язаного запису по кліку
  • Залишає стандартну поведінку видалення зв'язку через іконку delete
  • Підтримує стандартні опції створення та поле кольору

Використання

Підключіть віджет у XML-представленнях:

<field name="partner_ids" widget="many2many_click"/>

Опції налаштування

  • no_create
  • no_quick_create
  • no_create_edit
  • create
  • color_field
