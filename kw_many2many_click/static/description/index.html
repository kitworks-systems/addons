Many2Many Clickable Records


This module provides a clickable many2many widget for Odoo 18. It keeps the standard tag-like many2many appearance and adds convenient navigation: click item text to open the related record form in the current tab.

Key features include:

  • Works with all many2many fields
  • Opens related record form on click
  • Keeps standard unlink behavior on delete icon
  • Supports common create options and color field

Usage

Use the widget in XML views:

<field name="partner_ids" widget="many2many_click"/>

Configuration options

  • no_create
  • no_quick_create
  • no_create_edit
  • create
  • color_field
