Hide Discuss


This module provides functionality to control access to the Discuss menu in Odoo. It allows you to hide the Discuss menu from users who are not in the "Discuss user" group, helping to maintain a clean and relevant interface for each user role.

Key features include:

  • Group-based Access Control: Show/hide Discuss menu based on user groups
  • Simple Configuration: Easy to set up and manage user access
  • Clean Interface: Remove unnecessary menu items for non-discuss users

Configuration

User Access

  • Discuss User Group:
    • Add users to the "Discuss user" group to grant access
    • Users outside this group won't see the Discuss menu
  • Administrator Settings:
    • Administrators can manage group memberships
    • No additional configuration needed after installation
