=================================
Test KW HTML Image to Attachment
=================================

This module provides test cases for the kw_html_image2attachment module.

It tests:

* Creating records with external images
* Creating records with base64 images
* Updating records with images
* Cleaning unused images
* Marking attachments as HTML images
