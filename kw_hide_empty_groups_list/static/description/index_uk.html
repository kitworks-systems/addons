Приховування порожніх груп у згрупованих списках


Модуль приховує порожні групи у згрупованих list-представленнях для вибраних користувачів. Це корисно, коли у згрупованому списку є багато заголовків груп без записів.

Основні можливості:

  • Налаштування користувача: Hide empty groups in grouped lists
  • Передача параметра у frontend через session_info
  • Кастомний js_class для list-view: kw_filtered_grouped_list

Використання

  1. Встановіть модуль
  2. Увімкніть налаштування в Preferences користувача
  3. Додайте у list-view атрибут: js_class="kw_filtered_grouped_list"
<list js_class="kw_filtered_grouped_list">
    ...
</list>
