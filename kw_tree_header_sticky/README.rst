===================
Tree Header Sticky
===================

This module enhances the Odoo list view by making the header row sticky,
ensuring it remains visible when scrolling vertically through long lists.
This improvement significantly enhances user experience when working with large datasets.

Key Features
============

* Fixed header row while scrolling vertically
* Improved navigation in long list views
* Compatible with all Odoo list views
* No configuration needed
* Clean and modern interface

Configuration
=============

To use this module, you need to:

#. Install the module
#. No additional configuration needed - works automatically with all list views

Usage
=====

After installation:

#. Open any list view in Odoo
#. Scroll vertically to see the header row remain fixed at the top
#. Column headers always visible for easy reference
#. Works automatically with all list views

Technical Details
==================

CSS Implementation
------------------

* Uses modern CSS position: sticky
* Implements clean styling without JavaScript
* Compatible with Odoo's standard list view structure
* Minimal performance impact

Dependencies
-------------

* web: Base web module for backend interface
