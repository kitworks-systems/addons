Фіксований стовпець вибору в списку


Цей модуль покращує функціональність списків Odoo, фіксуючи стовпець з прапорцями вибору. При горизонтальному прокручуванні широких таблиць стовпець вибору залишається на місці, що значно покращує користувацький досвід при роботі з великими наборами даних.

Основні можливості:

  • Фіксований стовпець вибору: Стовпець з прапорцями залишається видимим при прокручуванні
  • Покращена зручність: Легкий вибір записів у широких списках
  • Універсальна сумісність: Працює з усіма списками Odoo
  • Нульова конфігурація: Працює одразу після встановлення
  • Сучасний інтерфейс: Чистий та адаптивний дизайн

Використання

Модуль працює автоматично після встановлення:

  1. Встановіть модуль
  2. Відкрийте будь-який список в Odoo
  3. Прокрутіть горизонтально, щоб побачити, як стовпець вибору залишається на місці
  4. Насолоджуйтесь покращеним вибором записів у широких таблицях

Переваги

  • Підвищена ефективність: Швидший вибір записів у широких списках
  • Краща навігація: Не потрібно прокручувати назад для вибору записів
  • Покращена видимість: Завжди видно, які записи вибрані
  • Універсальне застосування: Працює з усіма списками автоматично
  • Оптимізована продуктивність: Мінімальний вплив на системні ресурси
