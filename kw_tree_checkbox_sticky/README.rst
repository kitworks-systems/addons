======================
Tree Checkbox Sticky
======================

This module enhances the Odoo list view by making the checkbox column sticky,
ensuring it remains visible when scrolling horizontally through wide tables.
This improvement significantly enhances user experience when working with large datasets.

Key Features
============

* Fixed checkbox column while scrolling horizontally
* Improved selection experience in wide list views
* Compatible with all Odoo list views
* No configuration needed
* Clean and modern interface

Configuration
=============

To use this module, you need to:

#. Install the module
#. No additional configuration needed - works automatically with all list views

Usage
=====

After installation:

#. Open any list view in Odoo
#. Scroll horizontally to see the checkbox column remain fixed
#. Select multiple records easily, even in wide tables
#. Works automatically with all list views that have selection checkboxes

Technical Details
==================

CSS Implementation
------------------

* Uses modern CSS position: sticky
* Implements clean styling without JavaScript
* Compatible with Odoo's standard list view structure
* Minimal performance impact

Dependencies
-------------

* web: Base web module for backend interface
